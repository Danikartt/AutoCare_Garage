# AutoCare_Garage — Constitution

> Version: v1.0.0 · Ratified: 2026-11-24 · Last amended: 2026-11-24
> The non-negotiable principles every `rsc` SDD phase obeys.

## 1. Stack canon

1. Primary language and runtime: JavaScript (ES Modules, `"type": "module"`) on Node.js v18+, pinned in `package.json`.
2. Frameworks and persistence fixed: Express 5 (`express`) for the REST API and SQLite (`sqlite3`) for local storage. Changing either is a MAJOR amendment.
3. Package manager: `npm` with `package-lock.json` committed.

## 2. Quality bar

4. Every change must pass `npm test` (`node tests/maintenance.test.js`) with zero failures before completion.
5. Every new feature or bug fix includes at least one covering test in `tests/`.

## 3. Conventions

6. Directory boundaries: server code lives in `src/` (`data/`, `services/`, `utils/`, `server.js`), static frontend in `public/`, and tests in `tests/`.
7. API & errors: all HTTP endpoints live under `/api/v1/` and return JSON with standard HTTP status codes.

## 4. Branching & shipping

8. Changes land directly on the default branch (`main`) after passing `npm test` (`--workflow main`).
9. **Git authorship is the human's.** Commits are authored by the responsible person. No `Co-Authored-By` an AI, no "generated with" footer. Enforced at `ship`.

## 5. Security & privacy floor

10. No secret, local database (`data/*.db`), or log file (`*.log`) is ever committed; all remain excluded in `.gitignore`.
11. All SQLite queries use parameterized statements (no string-concatenated user input in SQL), checked with `security-audit`.

## 6. UX / accessibility floor

12. The web interface in `public/` maintains keyboard navigability, visible focus indicators, and readable contrast (WCAG 2.2 AA).

## 7. Knowledge & decisions

13. Every significant technical or scope decision is appended to `02-DOCS/wiki/harness/decisions.md` (date, options, why). The constitution is the highest-order decision record.

## Definition of Done (the merge bar `verify` runs against)

A change ships only when ALL hold:

- [ ] `npm test` passes with zero failures (principle 4).
- [ ] New features and bug fixes are covered by tests in `tests/` (principle 5).
- [ ] Directory boundaries (`src/`, `public/`, `tests/`) and `/api/v1/` API conventions respected (principles 6–7).
- [ ] No secrets, `.db` files, or logs staged; SQLite queries parameterized (principles 10–11).
- [ ] UI changes in `public/` remain keyboard-navigable with visible focus and WCAG AA contrast (principle 12).
- [ ] Landed on `main` with human git authorship and significant decisions logged (principles 8–9, 13).
